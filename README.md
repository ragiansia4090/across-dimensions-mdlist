# ACROSS DIMENSIONS MD 체크리스트

이세계아이돌 2nd 미니앨범 팝업스토어 **ACROSS DIMENSIONS** 전체 MD 체크리스트예요. 이미지가 모두 들어간 HTML 파일 한 개라서 인터넷 없이도 열려요.

## 다운로드

**[AD_checklist.zip 받기](https://github.com/ragiansia4090/across-dimensions-mdlist/raw/main/AD_checklist.zip)** → 압축을 풀면 `AD_checklist.html`이 나와요. 브라우저로 열면 돼요.

## 기능

- 전체 28개 품목의 옵션별 수량을 체크할 수 있어요.
- 구매 제한 수량까지 차면 + 버튼이 잠겨요.
  - 기본은 품목별·옵션별 1인 2개예요.
  - 예외: 회중시계 1개, 공식 인형 멤버별 1개, 랜덤 포토카드 팩 5개까지예요.
- 합계 금액과 포토카드 특전(5만 원당 랜덤 1장, 30만 원 이상 6종 세트), 다음 랜덤 포카까지 남은 금액을 자동으로 계산해요.
- 보기 필터: 전체 / 담은 것만 / 안 담은 것만
- **💾 HTML로 저장**: 체크한 상태를 담은 HTML 파일로 저장해요. 저장한 파일을 열면 체크한 상태 그대로 열려요.
- **📂 불러오기**: 저장해 둔 HTML 파일에서 체크 상태를 불러와요.
